Tools for game development

Requirements, Unreal Blueprints and engine ports: tools for building and checking large game code with AI agents.

Closed loop fly-through

Requirements, use cases, code and tests drawn as one 3D graph. Fly through it, take the guided tour, or open the manual page for any part of it.

The closed loop tests the requirements an AI agent acts on, then holds them to the code and the tests it writes. Drawn with WebGPU, with a WebGL 2 fallback.

u2ue: Unity to Unreal

A toolkit that ports a Unity game to Unreal Engine 5. Its own tools convert effects, scenes, UI and materials and check each result against Unity; an AI model ports the game logic by the toolkit's written skill.

A reviewer reads a UML model instead of a diff. The page shows what it measured on a real port, and the whole manual.

03 · AI research

AI research

Making AI answers checkable: an engine that shows its evidence and refuses when it runs out, and public data for testing models.

BetaRuns in the browser

Knowledge engine

A knowledge engine with no neural weights over 66.4 million facts, running in your browser. Every answer carries a measured confidence and the sources behind it, and it refuses when the evidence runs out.

Its confidence curve was checked on held-out facts: 0.20 percentage points calibration error. It is being rebuilt with real entity identity; this build runs on the previous version of this site.

  • Calibration
  • JavaScript

BossBench

A benchmark that joins real entities by invented relations, so a model cannot pass it by being well read. Released CC0.

The preprint includes its own correction: the first headline figures were withdrawn and re-measured on four orders of magnitude more evidence.

04 · Other tools

Other tools

Two applied tools outside games.

Web appRuns in the browser

Casement Sheet

Measure a casement window by tape, photo or voice, and the diagnostic sheet fills in the rest from the offsets printed on it.

Taped, photo-read and calculated figures stay apart on screen and in the PDF. Exports PDF, CSV and DXF. Works without a key; corner finding, dictation and the chat box use your own Anthropic key.

  • Web app
  • 3D view
  • PDF and DXF

Open Casement Sheet

ExperimentRuns in the browser

Solar setup

A 3D ray-traced zoo of solar panel and mirror layouts, each scored on build cost and dollars per kWh over 25 years, against a measured year of hourly weather.

Fly with WASD, scrub the sun along its path, and click any panel for its row in the table.

  • Ray tracing
  • three.js
  • Cost model
