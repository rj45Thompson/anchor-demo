How sure is it, and why?

A knowledge engine with no neural weights. It answers from a graph of independently collected sources, and every answer carries a measured probability — not a guess.

How the number is computed

Count how many independent sources assert the fact. That count maps to a probability through a curve fitted against a held-out source the system never consults when answering.

Fitted on one half of the entities and tested on the other, split by subject so no entity appears on both sides. Expected calibration error: 0.20 percentage points across 496,464 held-out facts. The curve predicts — it is not describing its own training data.

The law

An anchor is a second source, not a second opinion. One source is close to a coin flip. A second independently collected source takes it to 87%. That lift survives controls for popularity, for shared lineage between sources, and for gaps in the reference set.

We also measured where it fails. In a program-synthesis domain where every available checker read the same evidence, five checkers that were provably independent of each other still bought nothing — because independence was never the constraint. Competence was.

What this demo is. A slice — 4,000 well-connected subjects and 180,000 facts out of 66.4 million — chosen by connectivity and never by confidence, so weakly-supported facts appear at their natural rate. When it doesn't know, it says so instead of inventing an answer. That refusal is the point.
No model runs here. The page loads a data file and counts sources in your browser — the same arithmetic the full system does over 66.4M facts.
