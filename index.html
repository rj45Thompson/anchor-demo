01 · u2ue · main project

u2ue: Unity to Unreal

A toolkit that ports a Unity game to Unreal Engine 5 and proves it is still the same game. The toolkit's code is private; its whole manual is public, every chapter listed below.

BetaToolkit and its whole manual

u2ue: Unity to Unreal

Its own tools convert the effects, scenes, UI and materials of a Unity game and hold each result to Unity on numbers. An AI model ports the game's rules into an engine-free model by the toolkit's written skill, so both engines run the same rule code.

A reviewer then reads a UML model instead of the code line by line: every use case step names the command that proves it.

  • 92.4 %of the particle emitters Unity draws are drawn in Unreal
  • 383 / 383game-rule results agree across Unity, .NET and Unreal
  • 99.97 %of 26,973 per-frame checks on the built effects hold

From u2ue's page, where each figure names the command that measured it on the reference port: a medium-sized turn-based tactics game moved from Unity to Unreal.

Have Claude install it

Paste this into a terminal, in the folder you want it in. It starts Claude Code with the build as its first task. Building needs Python with PyYAML, Node.js, a .NET 8 SDK and Unreal Engine 5 (it reads the engine's own headers), so Claude checks for those first and tells you what is missing.

04 · AI research

AI research

Making AI answers checkable: an engine that shows its evidence and refuses when it runs out, and public data for testing models.

BetaRuns in the browser

Knowledge engine

A knowledge engine with no neural weights over 66.4 million facts, running in your browser. Every answer carries a measured confidence and the sources behind it, and it refuses when the evidence runs out.

Its confidence curve was checked on held-out facts: 0.20 percentage points calibration error. It is being rebuilt with real entity identity; this build runs on the previous version of this site.

  • Knowledge graph
  • Calibration
  • JavaScript

Dataset and preprint

BossBench

A benchmark that joins real entities by invented relations, so a model cannot pass it by being well read. Released CC0.

The preprint includes its own correction: the first headline figures were withdrawn and re-measured on four orders of magnitude more evidence.

05 · Other tools

Other tools

Two applied tools outside games.

Web appRuns in the browser

Casement Sheet

Measure a casement window by tape, photo or voice, and the diagnostic sheet fills in the rest from the offsets printed on it.

Taped, photo-read and calculated figures stay apart on screen and in the PDF. Exports PDF, CSV and DXF. Works without a key; corner finding, dictation and the chat box use your own Anthropic key.
