How this is made. view/oo.js reads the pasted text into classes: a parent comes from the engine members a class uses on itself (the engine header that declares each is named in the class's comment), fields are typed from the pins that read or write them, components from the events bound to them, and the interface from the messages sent through it. Where the text does not say, the class says so instead of guessing. It is a reading form: it parses whole, and it does not compile, because the engine's own declarations are not in the pastes. The converter and the assembler are open: github.com/rj45Thompson/blueprint-view-source.

The samples are public pastes on blueprintue.com; their authors keep the rights, and any author's graphs come down on request.
