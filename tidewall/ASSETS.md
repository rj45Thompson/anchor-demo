# Tidewall (working title) - everything the page loads from outside this folder

Every code file the page serves from this folder is this game's own: rules, renderer, page and generated islands. No image, model,
map or sound file is read from any other game. The binary files are the models in `assets/models/` and the recorded sounds in
`assets/sound/`, each listed below with where it came from.

| What | Where it comes from | Licence | Loaded by |
|---|---|---|---|
| three.js 0.175.0 (WebGPU build `three.webgpu.js`, `three.tsl.js`, addons under `examples/jsm/`) | https://cdn.jsdelivr.net/npm/three@0.175.0/ | MIT (Copyright 2010-2025 three.js authors) | the import map in `index.html` |
| PhonePad host script `phonepad-host.js` (phones as gamepads: room, QR code, WebRTC link) | `PHONEPAD_RELAY` + `/phonepad-host.js` (the relay address is the one constant in `app/phones.js`) | MIT (D:/_phonepad/LICENSE, the site owner's own project) | `app/phones.js`, `import()` when a join screen first opens a room |
| PhonePad relay (the phone's controller page and the room's messages) | `PHONEPAD_RELAY` in `app/phones.js` | MIT (same project) | the PhonePad host script (WebSocket), and each phone's browser |

Maps: generated by `app/maps.js` from seeds (original generator; names are original). Checked by the rules' MapCheck with
`node tools/check_maps.mjs`.

Sounds: recorded, CC0 (below), played by `app/sound.js` from the one table `app/soundbank.js`; the ported Synth (`core/audio/`)
still makes the one sound the soundbank keeps on purpose (the last-piece snare: the library has no drum).

Fonts: the browser's own system fonts (no web font is loaded).

spec-gloss extension). The bricks kit (`art_in/sketchfab/bricks.glb`) was LOOKED at and not used: its texture is a red clay brick
sheet, not the chunky grey stone the walls are, so the walls stay procedural (render/look.js). The Sketchfab "Cartoon Knight"
(`art_in/sketchfab/knight.glb`) was LOOKED at beside the Meshy knight (`shots/look/hero_compare.png`) and not used: its one clip is
an idle, the hero needs walking and running (UC-P3) and a swing, and its red tunic would read as player 2's colour on every hero.

## Sounds (`assets/sound/`, made by `tools/sound/build.mjs` from the staged library)

Every recording is CC0 (public domain dedication, https://creativecommons.org/publicdomain/zero/1.0/): the Kenney packs' own
License.txt, and each OpenGameArt file's licence as read on its page (2026-11-09). CC0 asks no credit; the title screen's footer
names every author anyway (`app/credits.js`). The build cuts silence, cuts and loops, sets the loudness (the body of each sound at
-16 dBFS, no peak above -1 dBFS) and encodes Ogg Opus, effects mono at 48 kbps, music stereo at 88 kbps (every file measured at
<= 96 kbps), ambience at 64 kbps. Each was CHOSEN BY A MEASUREMENT (duration, loudness, spectral centroid, pitch slope, busyness),
not by ear; the full reason is the `why` of its entry in `app/soundbank.js`. 36 files, 1,942,787 bytes (1.85 MB) in all.
