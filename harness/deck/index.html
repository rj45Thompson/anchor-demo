How it learns

A graph neural network (GNN) proposes what the graph is missing

How it works

Reads. Each node starts as its own words, hashed to 512 numbers.

Listens. GraphSAGE layers let each node hear its neighbours, relation by relation.

Ranks. A scorer ranks every requirement for a decision with no owner.

Asks. Below 70% sure it abstains. Above, its answer goes out as a question, never a verdict.

Never reads breaks, tests or chains. They hold the answer, and new code has none.

What it records

Score, when a pass runs it: beside the best plain rule, the words alone and random.

Each job, per project and per seed: the next slide. Some verdicts flip with the seed alone.

Breaks ranked: how many survivors the first fifth of a run holds, against the plain rule and random.

What it reads: its nodes and links, and how many of them are owner links.

More requirements: its score by how much of the links it can see.

How sure: at 70% sure, how often it is right, and on how much of the new code.

Every tune: each variant’s score, and what was kept.

How it tries to improve

The stats call it. When its lead over the plain rules falls, the stats name a tune as a next job. It is due after 5 passes anyway.

A tune redraws what it reads: each relation left out, each derived link added.

The bar: kept only if it wins by 0.02, then again on a seed it was not chosen on.

So far: tunes have been run and nothing was kept: no variant won by the bar.

The loop, in pseudo C++

One pass, then one tick

// One pass. Self-improvement is on by default.
Verdict run(Model& m, bool selfImprove = true) {
  Breaks  b = Mutate(m.code);       // one compile
  Results r = RunEachAlone(b, m.tests);
  Graph   g = KnowledgeGraph(m, r);
  Holes   h = Criteria(g);          // 18 checks

  if (self_improve_on(m, selfImprove)) {
    Row row = PassStats(m).collect();  // 44 stats
    MorphLog(m).add(row);
    auto fired = improvement::fires(rules, log);
    Print(NextImprovement(log, fired).picks());
  }

  return h.ours.empty() ? HOLDS : OPEN;
}

// One tick. A fresh agent, one item, no memory.
void Tick() {
  Start s = loop_tick::start();     // the lock
  if (s.stopped || s.busy || s.idle) return;
  if (s.epochStarts) Brainstorm();  // every 12
  RunSelftests();                   // red = item
  telemetry_audit();                // unread = item
  Item i = Choose(improvement::check(), board);
  Stat before = i.stat.Measure();
  i.Do();                           // one change
  Stat after = i.stat.Measure();
  if (s.epochEnds) {
    run_plan::decide();            // parts on or off
    improvement::graph();           // did it work?
  }
  loop_tick::finish(i, before, after, worth);
}

The same shape, one level up: stats are its code, triggers its requirements, ticks its tests. Three ticks worth “no” in a row and it sleeps until something changes.
