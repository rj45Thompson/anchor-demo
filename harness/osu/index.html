This is the requirements graph of the scoring rules of osu!, a shipped open-source game under the MIT licence (ppy/osu, commit 845336e), written from the code's own doc comments. Point at a node to read its name. The other fly-through hides names because that code belongs to a client; this one has nothing to hide.
