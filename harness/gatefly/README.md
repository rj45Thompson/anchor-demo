# The gate fly-through

Fly around a net that actually plays a game, hover a neuron or a layer, and read the gate: how
much of what you try to write at that unit actually arrives, given every other unit writing into
the same space.

## Open it

Serve the repo root and open the page. Any static server will do:

```bash
python -m http.server 8777
```

Then `http://localhost:8777/harness/gatefly/index.html`, and `?net=pong` for the other one. The
picker at the top lists whatever blueprints are on disk, from `nets.json`.

## Controls

- **drag** to orbit, **wheel** to zoom, **W/S** in and out, **A/D** sideways, **Q/E** up and down
- **hover** a unit for its gate, `a`, `c` and `c/a`; hover a layer's label for the layer's figures
- **Colour** cycles gate / a / c / live activation
- **Play the game** runs the net in the page - tic-tac-toe against a perfect minimax opponent,
  or pong against perfect interception
- **Measure the draw** times the scene and prints the median and p95

## What the numbers are

`gate = g(a - c)`, `g(x) = x/(1+x)`, where `a` is addressability and `c` is crowding - the Schur
complement of this unit's write direction against all the others. The arithmetic is the ratchet
lane's (`closed_loop_lite/ratchet/gate_blueprint.py`, `effective_a.py`); `gatefly/gate_math.py`
carries a plant that recomputes it with that lane's own functions and refuses on disagreement.
It currently agrees to exactly 0.0.

**A gate is not an activation.** The gate is a property of the weights and does not change as
the net runs. The live colour mode shows the activation, which does, and the page says so.

## Where the files come from

| file | written by |
|---|---|
| `nb_<net>.json` | `gatefly/gate_read.py --name <net>` |
| `<net>.f16`, `<net>.meta.json` | the trainer; copied here so the page can RUN the net |
| `nets.json` | `gate_read.py`, listing what is actually present |

## Why this is not `harness/fly/`

`harness/fly/index.html` is generated by `.opus-tools/autobot/fly_manual.py`, so a hand edit
there is overwritten; and its `data.json` contract is the manual's - `nodeRows`, `harmony`,
`readers`, `statMarks`, slide panels - none of which a net has. Filling those with placeholders
to borrow the renderer would be staging. `gatefly/NEURAL_BLUEPRINT.md` lists the specific fields
that do not fit and what replaced them.
